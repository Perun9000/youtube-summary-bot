# YouTube Summary Telegram Bot

Telegram-бот для саммари YouTube-видео: краткий обзор в чате и подробный
конспект по главам в Telegra.ph. Принимает ссылки в Telegram и из расширения
браузера. [Открыть бота](https://telegram.me/YouTube_Sum_mary_bot).

## Возможности

- **Саммари по ссылке.** Обзор, главы с таймкодами, теги, время чтения и
  топ-комментарий YouTube. Полный конспект публикуется в Telegra.ph; при
  ошибке публикации краткое саммари всё равно приходит в чат.
- **Субтитры или распознавание речи.** Если субтитров нет, бот скачивает аудио
  через yt-dlp и распознаёт его через Groq Whisper API. Работоспособность
  загрузки зависит от ограничений YouTube и доступности сети.
- **Сверка имён.** Название, очищенное описание и официальные главы помогают
  модели уточнить написание имён и терминов. Рекламные строки, ссылки и
  хэштеги отфильтровываются; описание ограничено 800 символами и используется
  как справочный материал. Это снижает, но не исключает ошибки модели.
- **Очередь и кэш.** Приоритеты для владельца, allowlist и подписчиков;
  сохранение задач в SQLite, восстановление после перезапуска, отложенные
  повторы сетевых сбоев и обработка премьер после выхода. Готовые саммари
  выдаются из кэша без новой генерации; кэш разделён по языкам.
- **7 языков:** русский, английский, испанский, португальский, арабский,
  фарси и индонезийский. Автовыбор по Telegram-профилю или `/language`.
- **Свой промпт:** `/myprompt` для владельца, тестировщиков из allowlist и
  активных подписчиков. Одноразовые пожелания к стилю и фокусу, до 500
  символов; пользовательский результат не попадает в общий кэш.
- **Архив:** `/last` возвращает последние 20 саммари по запросу.
- **Подписка и лимиты.** Telegram Stars, бесплатные квоты, проверка остатка,
  возвраты владельцем и маршрутизация запросов по тарифу.
- **Возможности владельца:** управление доступом, очередью, моделями,
  системным промптом, кэшем и просмотр статистики. Кнопки скачивания аудио,
  сохранённого транскрипта и подготовки сообщения для шеринга.
- **Реферальный тест.** Владелец может подготовить сообщение с личной
  ссылкой; новые пользователи получают саммари и first-touch-привязку.
  Награды и выплаты за рефералов пока не реализованы.

## Что отключено или ещё не реализовано

| Возможность | Текущее состояние |
|---|---|
| Мониторинг каналов и автоматический утренний дайджест | Отключены: `MONITORING_ENABLED=false`; команды сканирования скрыты из меню при выключенном флаге. Код сохранён для явного включения. |
| Публикация саммари в Telegram-канал | Отключена в коде; активного обработчика кнопки публикации нет. |
| Закреплённое сообщение с последними саммари | Удалено; используется `/last`. |
| Еженедельный отчёт владельцу и массовые рассылки | Пока не реализованы; `/stats` запускается вручную. |
| Параллельная аудио-очередь и автоматические аудиовложения | Пока не реализованы; доступна отдельная кнопка скачивания аудио владельцу. |
| Chrome Web Store / Firefox Add-ons | Публикация не выполнена. Текущий пакет предназначен для ручной установки в Chromium; Firefox требует отдельной адаптации фонового скрипта и проверки. |

Ошибки отдельных загрузок YouTube и временные отказы Telegra.ph не означают,
что эти функции полностью выключены: предусмотрены сообщения об ошибках и
резервные пути. Локальная модель LM Studio поддерживается кодом, но в
действующем экземпляре не используется.

## Быстрый запуск с OpenRouter

Нужны Docker с Compose, токен Telegram-бота от BotFather и ключ OpenRouter.
Для распознавания роликов без субтитров нужен отдельный ключ Groq.

```sh
git clone https://github.com/Perun9000/youtube-summary-bot.git
cd youtube-summary-bot
cp .env.example .env
```

Заполните `.env` (значения ниже — пример, а не секреты действующего бота):

```dotenv
TELEGRAM_BOT_TOKEN=<токен BotFather>
OWNER_USER_ID=<ваш Telegram ID>
LLM_PROVIDER=openrouter
OPENROUTER_API_KEY=<ключ OpenRouter>
# Задайте актуальные ID моделей из каталога OpenRouter:
OPENROUTER_MODEL_FREE_CHAIN=<model-a:free>,<model-b:free>
OPENROUTER_MODEL_PAID=<paid-model-id>
GROQ_API_KEY=<ключ Groq, необязательно>
PUBLIC_MODE=false
MONITORING_ENABLED=false
YTDLP_USE_COOKIES=false
```

Free-модели могут исчезать из каталога или отвечать 429. Не копируйте
устаревшие списки моделей: выберите текущие ID в [OpenRouter](https://openrouter.ai/models).

```sh
docker compose up -d --build
docker compose logs -f bot
```

Отправьте боту `/start` и ссылку на видео. По умолчанию `.env.example`
оставляет доступ закрытым: владелец и allowlist. Для публичного доступа
явно установите `PUBLIC_MODE=true`.

Compose также запускает `bgutil-provider` для PO-токенов yt-dlp.
В Docker-образ включены ffmpeg и среда выполнения JavaScript для
YouTube-челленджей. GPU для облачного режима не нужен.

### Модели и резервные пути

OpenRouter поддерживает приоритетную free-цепочку, повторы, ограничение
бюджета и circuit breaker. При исчерпании выбранных free-моделей бот может
попробовать до трёх дополнительных моделей из каталога, отобранных по
контексту и фильтрам. Фильтр не гарантирует одинакового качества всех моделей.
Для подписчиков есть переход к платной модели при недоступности или
слишком долгом ответе free-цепочки; бесплатные пользователи платный путь
не используют. Владелец управляет глобальным режимом через `/llm_paid`.

Модель должна вернуть структурированный JSON. Есть восстановление
повреждённого ответа, проверки вырожденных повторов и пустого результата,
повторы и обработка обрыва по лимиту токенов. Сырой неструктурированный
ответ не используется как готовый обзор.

Альтернативный режим — `LLM_PROVIDER=lmstudio` с локальным сервером
`LMSTUDIO_BASE_URL=http://host.docker.internal:1234`. Модель и размер
контекста нужно настроить в LM Studio; автозагрузка по умолчанию выключена.

## Пользовательские команды

- `/start`, `/help` — начало работы и инструкция.
- `/last` — последние 20 саммари.
- `/language` — язык интерфейса и саммари.
- `/limits`, `/subscribe`, `/paysupport` — лимиты, подписка и поддержка оплаты.
- `/myprompt` — одноразовый промпт (владелец, allowlist, подписчики).

Пример собственного промпта:

```text
/myprompt Сделай упор на цифры и выводы https://www.youtube.com/watch?v=VIDEO_ID
```

После команды без аргументов есть 5 минут на ввод. Промпт и ссылку можно
прислать вместе; если пришёл только промпт, бот ждёт ссылку 15 минут.
Если пришла только ссылка, делает обычное саммари. Пожелания меняют стиль
и фокус, но не JSON-формат, язык и требование опираться на транскрипт.
При финальной ошибке промпт возвращается в ожидание ссылки на 15 минут.
Текст пожеланий сохраняется в аналитике. Состояние промпта временное:
при перезапуске оно теряется, в том числе у восстановленных задач.

## Команды владельца

- `/users`, `/user_add`, `/user_remove` — управление allowlist тестировщиков.
- `/queue`, `/stop` — очередь и остановка задач.
- `/models`, `/model`, `/llm_mode`, `/llm_paid` — модели и режим генерации.
- `/stats` — отчёт по доступным логам за последние 30 дней и данным БД.
- `/cache_drop` — удалить саммари ролика на всех языках и сохранённый транскрипт.
- `/prompt_set`, `/prompt_show`, `/prompt_reset` — системный промпт.
- `/refund` — возврат платежа Stars.

`/scan_now` и `/scan_stop` доступны только при явном включении мониторинга;
при выключенном флаге вручную введённая команда сообщает, что он отключён.

## Подписка

При `PUBLIC_MODE=true` новые пользователи получают 3 стартовых саммари,
затем 1 бесплатное в неделю. Подписка по умолчанию стоит 149 Stars в месяц
и даёт 30 саммари. Ролик без субтитров длиннее часа списывает 2 единицы.
Кэшированная выдача не требует новой генерации. Владелец и allowlist
пользуются без квот; это также тестовая группа для `/myprompt`.

Параметры: `QUOTA_STARTER`, `QUOTA_FREE_WEEKLY`, `QUOTA_SUB_MONTHLY`,
`SUBSCRIPTION_PRICE_STARS`, `HEAVY_DURATION_SEC`.
Полные технические ошибки предназначены владельцу; остальные получают
пользовательские сообщения об ошибках.

## Расширение браузера

В [browser-extension/](browser-extension/) находится расширение 0.2.8
для ручной установки в Chrome / Edge / Brave и других Chromium-браузерах.
Кнопка Summary есть на странице видео и превью YouTube.

Обычный путь открывает бота через `telegram.me` с ID видео. Для владельца
доступен тихий путь без открытия Telegram: задайте `LOCAL_API_TOKEN` в
`.env` и тот же токен в настройках расширения. Запрос идёт через фоновый
скрипт к `http://127.0.0.1:8799/enqueue`, результат приходит в чат владельца.
API требует `OWNER_USER_ID`, порт опубликован только на loopback.
При недоступности API расширение возвращается к Telegram-ссылке.
Токен нельзя включать в распространяемый пакет расширения.

Инструкция: [browser-extension/README.md](browser-extension/README.md).
Текущий manifest использует `background.service_worker`; полноценная
поддержка Firefox и публикация в магазинах остаются отдельными задачами.

## Данные, логи и эксплуатация

Состояние хранится в `data/bot.db` (SQLite WAL): пользователи, очередь,
кэш, история `/last`, подписки, расходы квот, рефералы и аналитика.
Транскрипты сохраняются в `data/transcripts/`; временное аудио — в
`data/audio/`. Старые JSON-хранилища импортируются там, где сохранена
миграция; старые закрепления дайджестов больше не используются.

Кэш по умолчанию хранится 100 дней (`SUMMARY_CACHE_TTL_DAYS`). Логи
`data/logs/bot.log` ротируются ежедневно, сохраняется до 30 архивов.
Секреты находятся в `.env` и `data/`: не публикуйте их, включая резервные
копии настроек и VPN-ключи.

Cookies YouTube выключены по умолчанию. Если они необходимы для доступного
вашему аккаунту ролика, включите `YTDLP_USE_COOKIES=true` и задайте
`YTDLP_COOKIES_PATH` либо каталог `YTDLP_COOKIES_DIR` для ротации аккаунтов.
Cookies и PO-токены не гарантируют доступа к платным, приватным или
ограниченным по региону видео. Идущие прямые эфиры могут не скачиваться.

На macOS при работающем Docker читайте SQLite через контейнер: доступ
к той же WAL-базе одновременно с хоста и из Linux-VM может давать
несогласованные данные. Для внешних правок и копирования данных сначала
остановите бот. Перед обновлением дождитесь пустой очереди; два polling-
экземпляра с одним токеном Telegram одновременно запускать нельзя.

При работе через прокси извлечение метаданных YouTube и скачивание медиа
должны использовать один выходной IP. Инструкции серверного размещения и
Paper VPN: [docs/ops/README.md](docs/ops/README.md).

## Проверки

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt -r requirements-dev.txt
.venv/bin/python -m pytest -q
```

Аналитика логов: `scripts/analytics.py` (параметры — через `--help`).
Время обработки зависит от длины ролика, количества вызовов модели,
доступности провайдеров и очереди; мгновенная генерация не гарантируется.
